# FrontDesk

FrontDesk is a mobile-first news website for daily Nigerian news, international headlines, technology updates, urban lifestyle and entertainment bits.

## Stack

- Vite
- React
- Tailwind CSS
- Phosphor Icons

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel settings

- Framework: Vite
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

## Claude Code

Claude Code can be installed globally on your machine or VM:

```bash
npm install -g @anthropic-ai/claude-code
```

Then run inside the repo:

```bash
claude
```

This project also includes an npm helper:

```bash
npm run claude
```
